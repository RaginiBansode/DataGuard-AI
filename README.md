# DataGuard AI – Smart Data Analysis Platform

## About the Project

DataGuard AI is a Python-based data analysis application built using Streamlit. It helps users explore datasets, visualize data, handle missing values, and generate AI-powered insights.

## Features

* Upload CSV and Excel files
* Dataset preview and summary statistics
* Missing value detection
* Interactive charts using Plotly
* Smart data cleaning
* Download cleaned datasets as CSV
* AI Data Assistant powered by Google Gemini

## Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Plotly
* Google Gemini API

## How to Run

1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Configure your Gemini API key securely using Streamlit secrets.
4. Run `streamlit run app.py`.
